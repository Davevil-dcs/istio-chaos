# Proyecto de Computación Tolerante a Fallos

## Entorno
- Kubernetes
- Istio
- Aplicación Bookinfo

## Objetivo
Demostrar mecanismos de tolerancia a fallos
mediante experimentos controlados con microservicios.

## Experimentos
1. Caída de microservicios.
2. Reintentos (Retries).
3. Tiempo de espera (Timeouts).
4. Circuit Breaker.
